# Shimond 海外推广方案

> B2B 工业品牌海外曝光 + 询盘转化
> 制定日期：2026-07-30

---

## 总体策略

**定位**：B2B 工业品牌海外曝光 + 询盘转化
**核心逻辑**：SEO 做地基（长期流量）→ 社交做触点（品牌渗透）→ 付费做加速（快速起量）→ 邮件做转化（培育线索）

**关键原则**：
- 英文内容为主，内容一次生产、多渠道分发
- 每个社交平台角色不同，不重复搬运，要按平台特性改造
- 所有渠道最终引流到官网落地页，转化在官网发生

---

## 阶段一：技术地基（Week 1-2）

### 1.1 SEO 技术设施

| 项目 | 说明 |
|---|---|
| `sitemap.xml` | Next.js `app/sitemap.ts` 自动生成，包含 products/cases/news |
| `robots.txt` | 允许抓取，屏蔽 `/admin/*`，指向 sitemap |
| 页面 metadata | 每页独立 title/description/canonical/OG/Twitter Card |
| JSON-LD 结构化数据 | Organization、Product、Article、BreadcrumbList |
| 多语言 hreflang | 若启用 i18n，声明 en 为默认、其他为备选 |
| 面包屑导航 | 帮助爬虫理解层级 |

### 1.2 性能与体验

- Core Web Vitals 达标（LCP<2.5s、INP<200ms、CLS<0.1）
- 移动端优先适配
- 图片 next/image + WebP + lazy load
- HTTPS 全站

### 1.3 监控埋点

- Google Analytics 4（主流量分析）
- Google Search Console（收录/索引/关键词）
- Google Tag Manager（统一管理脚本）
- Microsoft Clarity（免费热图 + 会话回放，看用户行为）
- 转化目标：联系表单提交、产品咨询点击、WhatsApp 点击

## 阶段二：Google 收录（Week 2-3）

1. Search Console 验证站点
2. 提交 sitemap
3. 检查索引覆盖率，处理 404/抓取异常
4. 提交重点页面 URL 手动请求索引（产品页、核心案例页）
5. 监控「网页编入索引」报告，持续修复问题

## 阶段三：内容策略（Week 3 起，长期持续）

### 3.1 关键词研究

- 工具：Google Keyword Planner、Ahrefs/SEMrush（有预算）、Ubersuggest（免费）
- 三个层级：
  - **核心词**：你的产品品类词（搜索量大，竞争大，做产品页）
  - **长尾词**：产品 + 应用场景/材质/规格（做 news 文章）
  - **痛点词**：how to choose / X vs Y / common problems（做对比/指南文章）

### 3.2 内容生产节奏

| 内容类型 | 频率 | 目的 |
|---|---|---|
| 产品页完善 | 一次性 + 定期迭代 | 核心转化页 |
| 案例（Cases） | 1-2 篇/月 | 信任建立 |
| News/博客 | 2-4 篇/月 | SEO 流量 + 行业权威 |
| 行业指南/白皮书 | 1 篇/季 | 高质量引流 + 邮件诱饵 |

### 3.3 内容多渠道分发原则

一篇文章写完后，按平台改造分发（不是直接搬运）：

| 原始内容 | LinkedIn | YouTube | TikTok | Facebook |
|---|---|---|---|---|
| 案例 | 长文 + 数据 | 案例视频解说 | 30s 高光 | 摘要 + 链接 |
| 指南文章 | 轮播图/长文 | 教程视频 | 1分钟干货 | 总结贴 |
| 产品介绍 | 规格亮点帖 | 产品演示视频 | 使用场景短片 | 图片轮播 |

## 阶段四：社交媒体矩阵（Week 3 起）

### 各平台角色定位

#### LinkedIn（B2B 核心，最高优先级）

- **目标**：触达采购决策者、行业客户、建立专业形象
- **内容**：公司动态、案例深度解析、行业洞察、员工/团队展示
- **形式**：长文 Post、轮播图 PDF、Article、公司页定期更新
- **动作**：
  - 建立公司页（Company Page）+ 完善介绍/Logo/横幅
  - 鼓励员工完善个人页并关注公司页
  - 每周 3-5 条更新
  - 加入行业 Group 参与讨论
  - 后期投 LinkedIn Ads（精准定向职位/行业）

#### YouTube（信任与深度内容）

- **目标**：产品演示、案例视频、工厂/能力展示，建立海外客户信任
- **内容**：
  - 产品演示视频（每个核心产品一条）
  - 工厂/产线实拍
  - 客户案例访谈
  - 行业知识科普
- **SEO**：YouTube 是全球第二大搜索引擎，标题/描述/标签要优化
- **频率**：每月 2-4 条

#### TikTok（年轻流量 + 算法红利）

- **目标**：品牌曝光、触达年轻采购群体、低成本起量
- **内容**：工厂幕后、生产过程、产品使用场景、行业趣味内容
- **形式**：15-60 秒短视频，前 3 秒抓人
- **频率**：每周 3-5 条（量大才有算法推荐）
- **注意**：B2B 转化路径长，主要是品牌曝光，不要指望直接询盘

#### Facebook（品牌主页 + 社群）

- **目标**：品牌主页存在感、轻量互动、部分社群运营
- **内容**：公司动态、产品更新、案例摘要
- **动作**：
  - 建立公司主页
  - 每周 2-3 条更新
  - 视行业情况建 Group（行业交流社群）
  - 后期投 Facebook Ads（再营销 + 兴趣定向）

#### Instagram（视觉品牌）

- **目标**：视觉化品牌形象（如果产品有视觉表现力）
- **内容**：产品图、工厂实拍、团队、展会
- **形式**：Feed 图、Reels 短视频、Stories
- **频率**：每周 2-3 条

> Instagram 和 Facebook 同属 Meta，可共用 Meta Business Suite 管理和投流。

### 社交矩阵落地步骤

1. 注册所有平台官方账号，统一品牌名/Logo/简介
2. 各主页放官网链接
3. 制定内容日历（建议用 Notion / Trello / Loomly）
4. 先集中做好 1-2 个平台有起色，再扩展其他

**优先级建议**：LinkedIn > YouTube > TikTok > Facebook > Instagram

## 阶段五：付费投放（Week 6 起，有预算后）

| 渠道 | 用途 | 定向方式 |
|---|---|---|
| Google Search Ads | 捕获主动搜索需求（高意图） | 关键词 |
| Google Display Ads | 再营销 + 品牌曝光 | 再营销列表/兴趣 |
| LinkedIn Ads | 精准触达决策者 | 职位/行业/公司规模 |
| Facebook/IG Ads | 兴趣定向 + 再营销 | 兴趣/行为 |
| YouTube Ads | 视频前贴片 | 兴趣/再营销 |

**投放节奏**：先小预算测试（找到 CTR 高、CPL 低的组合），再放量。每个渠道单独追踪转化成本。

---

## 阶段六：邮件营销（Week 8 起）

1. 官网放 Newsletter 订阅入口（用行业指南/白皮书作为诱饵）
2. 工具：Mailchimp（起步免费）/ Brevo / ConvertKit
3. 自动化流程：
   - 欢迎邮件
   - 内容培育序列（每周 1 封有价值内容）
   - 询盘跟进序列
4. 询盘客户单独进入销售培育流程

## 阶段七：数据与迭代（持续）

### 每周检查

- Search Console：新收录页面、关键词曝光变化、抓取错误
- GA4：流量来源、落地页表现、转化漏斗
- 各社交平台：粉丝增长、互动率、引流到官网的点击

### 每月复盘

- 哪些内容/渠道带来最多询盘
- 投放 ROI（每个渠道 CPL、CAC）
- 下月内容计划调整

### 关键指标

| 层级 | 指标 |
|---|---|
| 流量 | 自然搜索流量、社交流量 |
| 互动 | 跳出率、停留时长、页面深度 |
| 转化 | 询盘数、订阅数、WhatsApp 咨询数 |
| 商业 | 询盘成本、成交转化率、ROI |

## 执行优先级总览

```
Week 1-2:  技术 SEO + 埋点监控
Week 2-3:  Google 收录 + 社交账号注册搭建
Week 3+:   内容持续生产 + 社交运营启动（LinkedIn/YouTube 优先）
Week 6+:   付费投放测试
Week 8+:   邮件营销启动
持续:      数据复盘 + 内容迭代
```
